# clemens-code/homebrew-tap

Homebrew tap for [KimaiClock](https://github.com/clemens-code/kimai-clock), a macOS menu bar app for Kimai 2 time tracking.

```bash
brew install --cask clemens-code/tap/kimai-clock
```

Update with `brew upgrade --cask kimai-clock`. The cask in `Casks/` is updated automatically by the KimaiClock release workflow.
